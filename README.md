# libSteamSave

A library to allow you to upload and download arbitrary files to Steam's Cloud using your existing, lesser played, games.

Pros: You can store your mod files and stuff with your game! And saves for other games! Game need not be installed!
Cons: If you install a game you're using for this, you'll also end up downloading all of those files. I think. Untested tbh, Someone PR the answer!

Also; while Valve doesn't explicitly DISALLOW this, they also don't explicitly ALLOW it.

So keep that in mind!

That said I would bet if you're using it reasonably (to store save files and maybe mods), then I can see it be it being fine.

Oh and I'd probably upload files as encrypted archives, for safety.

Limitations: 200MB upload size, game will be shown as "open" when doing file transfers.
